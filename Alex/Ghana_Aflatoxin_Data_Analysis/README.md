### Ghana Aflatoxin 2013 Dataset 

All files in this repository relate to this project.

**Aflatoxins** are toxic compounds produced by certain *Aspergillus* fungi (mainly *Aspergillus flavus* and *Aspergillus parasiticus*) that contaminate crops such as maize and groundnut, particularly under warm and humid storage or field conditions. Exposure to aflatoxins in food poses serious health risks, including liver damage and increased cancer risk, making monitoring and early detection critical for food safety.

The dataset used in this project was collected in **2013**, covering a **single, unknown growing season**. It captures aflatoxin contamination levels alongside environmental, soil, and agronomic variables across maize and groundnut sampling sites in Ghana.

This data is intended to support the development of an **early warning system** for aflatoxin contamination, to be built together with the corresponding Nigeria dataset contributed by **Agnes Chisale**.

You can visualise the Ghana data here: [Ghana Aflatoxin 2013 Dataset Spatial Dashboard](https://alex-nyaga.github.io/Ghana-aflatoxin-web_2013_Dataset_IITA/)
